# Thư mục inbox/

Bỏ tài liệu bài giảng mới vào đây (video `.mp4/.mov`, ảnh `.png/.jpg`, `.pdf`, `.docx`) rồi gõ `/cap-nhat` trong Claude Code.

- File trong thư mục này **không được commit** lên git (video thường rất nặng) — xem `.gitignore`.
- Sau khi xử lý xong, file được chuyển sang `inbox/done/`.
- `inbox/.work/` là nơi lưu tạm khung hình, ảnh lưới, văn bản trích ra trong lúc xử lý.
